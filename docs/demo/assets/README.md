# Demo media sources

Publication copies in this directory support the GitHub Pages website. Original
captures, historical media backups, intermediate frames and review evidence are
retained under `/Users/sol/Codex/artifacts/convertsell-demo-refresh/`.

- Storefront screenshots and UI footage: public Purple CRO demonstration store,
  https://purplecrodemo.wpcomstaging.com/, captured November 19, 2026. Products,
  customer names, orders and review text shown there are demonstration content.
- Offer-placement and post-purchase explanation cards: authored project content,
  rendered from `tools/demo/cards.html`. These are explanations rather than
  payment or completed-order interfaces.
- Inter variable font: the same bundled file used by the Purple parent theme.
  See `OFL-Inter.txt` for its copyright and SIL Open Font License.
- The movie's burned-in descriptions have a matching HTML transcript. It is
  silent and does not start or download automatically on page load.
- The old custom-design video/poster are replaced in the deployed source only
  after their originals have been copied and SHA256-verified in the task archive.

Build and verification: `docs/demo-refresh.md` and `tools/demo/`.
